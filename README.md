# Java JDBC + PostgreSQL Integration

Projeto prático demonstrando a integração nativa da linguagem Java com o banco de dados relacional PostgreSQL utilizando a API JDBC (Java Database Connectivity).

## 🚀 Tecnologias Utilizadas

* **Java JDK 25+** (ou versão equivalente)
* **PostgreSQL** (Banco de dados relacional)
* **PostgreSQL JDBC Driver** (`org.postgresql:postgresql`)
* **Maven / Gradle** (Gerenciador de dependências)

## 📌 Funcionalidades Demonstradas

- [x] Conexão e desconexão segura com o banco PostgreSQL.
- [x] Operações completas de CRUD (Create, Read, Update, Delete).
- [x] Execução de *PreparedStatements* para prevenção de SQL Injection.
- [x] Manipulação de *ResultSet* para mapeamento de dados.
- [x] Gestão de Transações (*Commit* e *Rollback* manual).

## 🛠️ Pré-requisitos

Antes de iniciar, certifique-se de ter instalado em sua máquina:
1. **Java Development Kit (JDK)** versão 25 ou superior.
2. **PostgreSQL** rodando localmente ou via container Docker.
3. Sua IDE de preferência (IntelliJ IDEA, Eclipse ou VS Code).
